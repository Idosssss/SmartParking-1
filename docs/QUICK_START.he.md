# הפעלה מהירה: ESP32 + אתר

## 1. חיווט

| רכיב | חיבור |
| --- | --- |
| חיישן IR בכניסה: אות | **D34** |
| חיישן IR בחניה: אות | **D35** |
| פס לדים WS2812: DIN (צהוב) | **D26**, דרך נגד של כ-330 אוהם |
| פס לדים: +5V (אדום) | **VIN** |
| כל ה-GND | **GND** |

הכל מוזן מ-**VIN**, ושום דבר לא מחובר ל-3V3. מחברים את הצד **הנכנס** של פס הלדים (`+5V DIN GND`), לא את `DO`.

## 2. העלאת הקושחה

1. Arduino IDE: ב-Boards Manager מתקינים את **esp32** (Espressif), וב-Library Manager מתקינים את **Adafruit NeoPixel**.
2. פותחים את `hardware/smart_parking/smart_parking.ino`, בוחרים בלוח **ESP32 Dev Module** ובפורט, ולוחצים **Upload**.
3. בדיקה: ב-Serial Monitor (מהירות 115200) מופיעה שורת JSON כל 150ms עם `"state":"RUNNING"`, והלדים ירוקים.

## 3. חיבור לאתר

1. **סוגרים את ה-Serial Monitor.** רק תוכנה אחת יכולה להשתמש בפורט.
2. פותחים ב-Chrome או ב-Edge את https://technionparking.vercel.app ← **Open the live demo** ← **Connect Arduino** ← בוחרים את הפורט.
3. מכונית צעצוע מול חיישן הכניסה: הטלפון במסך מנחה אותה לחניה. מזיזים אותה מול חיישן החניה: הלדים הופכים לאדומים.

## 4. מה הלדים אומרים

| לדים | משמעות |
| --- | --- |
| ירוק / אדום | החניה פנויה / תפוסה |
| כחול | עולה (קבוע), או מכייל (מהבהב מהר) |
| כתום מהבהב | חיישן מקולקל: לבדוק את החוטים |
| הלד האחרון סגול | מצב mock: נתונים מדומים |
| הלד הראשון מהבהב בענבר | האתר הפסיק לדבר עם הלוח |

## 5. בלי חיישנים

- **על הלוח:** לחיצה קצרה על כפתור ה-BOOT, או הפקודה `MOCK ON`, מפעילה נתונים מדומים.
- **באתר:** "No board? Emulate the sensors".
- **לחזרה להגדרות ברירת המחדל:** מחזיקים את כפתור ה-BOOT 2 שניות.
