# מדריך למשתמש

Smart Parking מציג חניון, מוצא את החניה הפנויה הקרובה ביותר לרכב שמגיע ומנחה אותו אליה.
חניה אחת היא אמיתית: ESP32 עם שני חיישני IR ופס לדים. שאר החניון מדומה.
(English: [USER_GUIDE.md](USER_GUIDE.md))

## מה צריך

- מחשב עם **Chrome או Edge** (ב-Safari וב-Firefox אי אפשר לדבר עם USB)
- צומת החיישנים (ESP32) מחובר לפי [HARDWARE.md](HARDWARE.md), והקושחה נטענה
- האתר (הקישור של Vercel, או `npm run dev` ואז `http://localhost:5173`)

אין לוח? אפשר לנסות הכל עם האמולטור שעל המסך, או עם מצב ה-mock של הלוח.

## הפעלה

1. מחברים את הלוח למחשב בכבל USB. פס הלדים מהבהב **בכחול** לרגע ואז נדלק **בירוק** (החניה פנויה).
2. סוגרים את ה-Serial Monitor של Arduino IDE אם הוא פתוח.
3. פותחים את האתר. הוא נפתח בעמוד **Overview**; לוחצים **Open the live demo** ואז **Connect Arduino**. בוחרים את הפורט של הלוח (כתוב CP2102 או USB Serial).
4. בראש לוח Hardware כתוב **Board connected** ושני פסי החיישנים זזים. בפעם הבאה האתר יתחבר לבד.

## שימוש

1. **מציבים מכונית צעצוע מול חיישן הכניסה.** בטלפון מופיע "Car detected", אחר כך "Finding nearest spot",
   ואז הוראות ניווט, והמכונית נוסעת במפת החניון.
2. המכונית עוצרת ליד החניה האמיתית ("Pull into Spot S25"). **מזיזים את מכונית הצעצוע לחיישן החניה.**
   הלדים נדלקים **באדום** והאפליקציה מאשרת שחנית.
3. תג החיישן האמיתי (**HW**) עובר לחניה הבאה. מפנים את חיישן החניה ומביאים את המכונית הבאה.

עוד דברים לנסות: ללחוץ על חניה פנויה כדי למלא אותה, להפעיל **Live Traffic**, לגרור את תג **HW**
לחניה אחרת, ולעבור לעמוד **Simulation study** לראות את המספרים שמאחורי הניווט.

מתחת למפה:

- **Live sensor readings** מצייר את 30 השניות האחרונות של שני חיישני ה-IR יחד עם מרחקי ההפעלה, ומסמן
  ברקע את הרגעים שבהם הלוח החליט "מכונית" או "תפוס". **Pause** מקפיא את הגרף; **Export CSV** שומר את המדידות.
- **This session** סופר כמה מכוניות הונחו, את אורך הנסיעה הממוצע במטרים, ניתובים מחדש וחניות שאושרו
  בחיישן, ומצייר כמה החניון היה מלא לאורך הזמן. **Export CSV** שומר את הסיכום ואת כל יומן האירועים.

כפתור הירח / השמש בפינה העליונה מחליף בין ערכת צבעים בהירה לכהה.

## הגדרות

בלוח Hardware:

- **Entrance trigger / Spot trigger**: כמה קרוב (בסנטימטרים) צריך להיות משהו כדי להיחשב רכב / חניה תפוסה.
  ההגדרה נשמרת על הלוח.
- **Board settings and technician view** (נפתח בחץ הקטן): כפתורי **Calibrate** (קודם מציבים את המכונית במקום,
  ואז לוחצים), **Mock mode**, **LED brightness**, **Restore board defaults** ו-**Show raw data**.

## אם משהו לא עובד

| מה רואים | מה עושים |
| --- | --- |
| "Could not open the port..." | סוגרים את ה-Serial Monitor (או כל תוכנה אחרת שמשתמשת בלוח) ולוחצים Connect שוב |
| הפורט לא ברשימה | כבל USB שמעביר נתונים; להתקין את דרייבר CP2102; לחבר מחדש את הלוח |
| "Connected, but the board is not sending data" | לטעון שוב את הקושחה, לוודא שקצב התקשורת הוא 115200 |
| "Board not responding" | לבדוק את הכבל או ללחוץ על כפתור האיפוס של הלוח. הזיהוי חוזר לבד |
| "Lost connection to the board" | הכבל נשלף. מחברים חזרה והאתר מתחבר מחדש |
| "A sensor looks broken" ולדים כתומים | לבדוק את שלושת החוטים של אותו חיישן (אות, מתח, אדמה) |
| רכב מזוהה מוקדם או מאוחר מדי | לכייל (Board settings) או להזיז את מחוון ה-trigger |
| שום דבר לא עובד | להפעיל **Mock mode** כדי לראות שהאתר עובד, ואז לבדוק את החיווט |
| אין כפתור Connect | להשתמש ב-Chrome או Edge במחשב; או באמולטור |
